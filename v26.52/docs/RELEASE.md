# FullBright 0.1.0-test3-leftalt

**Windows x64 · Minecraft Bedrock 1.26.52.03 · LeviLauncher · Prerelease**

## English

- Adjustable gamma brightness **1–25**, default **12**; enabled by default.
- Live JSON settings and optional ModMenu controls.
- Single-key and **Ctrl / Shift / Left Alt** combination toggle, unbound by default.
- Exact game-image and gamma-entry checks retained.

Exit Minecraft before updating and **preserve your existing config.json**.
This package contains FullBright only. Configure requires a schema-v5-capable
ModMenu; the older public `0.5.0-test1` cannot open this description. JSON works
without ModMenu.

Offline checks passed. The original test1 was manually accepted; this updated
DLL still needs gameplay acceptance. Only 1.26.52.03 is supported, and RTX or
deferred/custom renderers are unverified.
